Note: This step is only required for Windows users who do not have a default SSH client.
If you're using macOS, Linux, or the latest build of Windows 10 or Windows 11, you can use the downloaded PEM file directly — in that case, skip this step and proceed to the next one.

Connecting to a running Linux instance using an SSH client requires a public/private key pair. Older builds of Windows 10 (prior to the April 2018 Update) and earlier do not include a built-in SSH client. PuTTY is a commonly used SSH client that is free to download and use. However, PuTTY does not support the PEM (Privacy Enhanced Mail) key format used by AWS. Therefore, the PEM key file must be converted to the PPK (PuTTY Private Key) format. Fortunately, PuTTYgen — also free to download and use — can convert PEM files to PPK format.

Summary
Now you are ready to use PuTTY for connecting to the running Linux instance created in a previous lab step. The PuTTY SSH client will use the key pair format it requires for the private key to connect to the instance. The running Linux instance already has the public key on it.
